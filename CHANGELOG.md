# Changelog

## [0.1.0] — 2026-09-12

Первый выпуск. Ядро выделено из `marketplaces-mcp-ru`, где оно жило внутри
репозитория, чтобы его могли делить серверы, живущие отдельными репозиториями.

- каталог методов из YAML, поиск по описанию, `describe`/`call`;
- класс доступа read/write/destructive, запись требует подтверждения;
- асинхронный HTTP-клиент: авторизация, повтор на 429, пагинация, белый список
  доменов, чтобы заголовок с ключом не ушёл на чужой хост;
- хранилище ключей на несколько кабинетов вне репозитория, права 600;
- `doctor`: отчёт о том, взлетит ли установка, со списком сервисов от вызывающего.
